# בקיבוץ — האתר

האתר החי: **https://bakibutz.netlify.app**

כל האתר הוא קובץ אחד: `public/index.html`. אין שרת, אין בסיס נתונים, אין שלב בנייה.
התמונות והפונטים מוטמעים בתוך הקובץ עצמו.

**כל `git push` לענף `main` מפרסם את האתר לאוויר אוטומטית** (תוך פחות מדקה).

---

## התקנה חד-פעמית במחשב חדש

1. **Git** — במק הוא כבר מותקן. בווינדוס: https://git-scm.com/download/win
2. **Node.js** (גרסה 18 ומעלה) — https://nodejs.org
3. **Claude Code**:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
   אחר כך `claude` ולהתחבר עם חשבון Claude (צריך מנוי Pro או Max — לכל אחד חשבון משלו).
4. **להוריד את הפרויקט**:
   ```bash
   git clone https://github.com/flomermer/bakibutz.git
   cd bakibutz
   ```
   בפעם הראשונה Git יבקש להתחבר ל-GitHub (שם משתמש + אישור בדפדפן).

## איך עובדים על האתר

מתוך תיקיית הפרויקט:

```bash
claude
```

ואז פשוט לבקש בעברית מה לשנות — למשל "תחליפי את התאריך של הסדנה הבאה ל-12.3" או
"תוסיפי תמונה חדשה לגלריה". קלוד מכיר את האתר: ההנחיות בשבילו יושבות ב-`CLAUDE.md`.

כשהשינוי מוכן, לבקש **`/deploy`** — קלוד יראה מה עומד לעלות לאוויר, יבקש אישור,
ידחוף ל-GitHub ויאמת שהאתר החי עלה.

## שני כללים חשובים

1. **לפני שמתחילים לערוך — תמיד למשוך את הגרסה העדכנית:**
   ```bash
   git pull --rebase
   ```
   (או פשוט לבקש מקלוד "תמשוך את הגרסה העדכנית").
2. **לא לעבוד בו-זמנית על האתר משני מחשבים.** כל האתר הוא קובץ ענק אחד, ואם שניכם
   תערכו אותו במקביל — מיזוג השינויים יהיה כמעט בלתי אפשרי, ואחד מהשינויים ילך לאיבוד.
   עדיף להגיד אחד לשני "אני נכנס לערוך".

## חלופה בלי טרמינל

אפשר גם לעבוד מהדפדפן דרך **claude.ai/code** — מתחברים שם לחשבון ה-GitHub, בוחרים את
הפרויקט `bakibutz`, ומבקשים שינויים בעברית בדיוק כמו בטרמינל. אין מה להתקין.
